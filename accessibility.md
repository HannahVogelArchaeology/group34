<h1 class="page-title">Accessibility</h1>

<section class="content-section" aria-label="Accessibility of the website">
    <h2 class="gold-heading">For Website</h2>
    <div class="sub-block" aria-label="Website accessibility information">
        <p class="section-desc" aria-label="Website description">
            This website offers several accessibility features to enhance usability for all users. Features include high colour contrast, sans-serif typefaces, adjustable text size, dark mode, and reduced motion effects for a more comfortable visual experience. ARIA labels and states support screen-reader users, and keyboard navigation enables access to all website features, including audio playback controls. A photo viewer guidance feature assists users in navigating the photo viewer. It also provides curator-supplied videos with closed captions, audio-visual descriptions, transcripts, and alternative text for images to further improve accessibility.        
        </p>
    </div>
</section>

<section class="content-section" aria-label="Accessibility of the on-campus display">

        </p>
        <ul class="section-desc" aria-label="List of accessibility features on campus display">
